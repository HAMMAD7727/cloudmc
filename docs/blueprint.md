# **App Name**: CloudMC Store

## Core Features:

- Homepage Display: Display featured coin packs and ranks on the homepage.
- Coin Packages: Show coin packages with prices and bonus details.
- Rank Listings: Display available ranks with included perks.
- Discord Integration: Provide a prominent link to the CloudMC Discord server.
- Purchase Flow: Open purchase instructions in a new tab when 'Buy Now' is clicked.
- News Feed: Display latest news and updates on the homepage.

## Style Guidelines:

- Primary color: Saturated blue (#4287f5), reflecting a cool, trustworthy feel, as well as the colors from the image provided.
- Background color: Light blue (#E8F4FF), a desaturated hue that maintains a bright interface.
- Accent color: Analogous purple (#9466FF), for calls to action.
- Body and headline font: 'Inter' sans-serif font, to bring a clean and modern aesthetic.
- Use the CloudMC logo image as a banner at the top of the homepage.
- Ensure a clean and intuitive layout that allows users to quickly find the information they need.
- Use a subtle hover effect on buttons and interactive elements to provide feedback to the user.
